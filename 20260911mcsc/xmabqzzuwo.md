# 【医疗动态】中西医联手  破解“不死的癌症”

> 更新时间：2026-09-11 (UTC+8)

脊柱如同人体的“承重墙”，支撑着躯干活动自如。可是有一种治疗难度高的疾病，被称为“不死的癌症”，它会逐渐引起脊柱畸形病变，身体功能丧失，甚至残疾。它就是强直性脊柱炎。南平市人民医院利用中西医疗法，帮助强直性脊柱炎患者改善生活质量。

三个月前，患者小张在家人的陪同下，坐着轮椅来到南平市人民医院风湿免疫科就诊。20岁的男孩本应该是阳光活力，意气风发的样子，但是这些词却在小张的生活中显得十分陌生。五年前，他反复腰背部疼痛，开始以为只是扭伤引发的，而后，腰背部出现夜间加剧，小张常常在睡梦中被痛醒，翻身也变得困难，可白天活动后身体的不适又好转许多。因为病情反复发作，疼痛还可以忍受，小张就没有太在意。直到去年，疼痛难耐的小张已经无法上学，入院检查后发现，原来他患上了强直性脊柱炎。经过一段时间的治疗，小张身体的疼痛得到缓解，就停止了药物，不再上医院复查。不想病情越发严重，今年二月份，小张已无法正常行走卧病在床，可没想到躺在床上休养，病情反而发展得更快。就翻身、坐起、下床，这一系列简单的动作，他都要花费10多少分钟，学业也因此受到严重影响。

在了解到小张的病情后，主治医生为小张制定了中西医治疗的方案。“强直性脊柱炎发病原因复杂，治疗难度较高，无法根治。中医认为，它是因风寒侵袭、机体劳累，邪湿所致，引起的脊柱僵直、疼痛、肿涨、行走不便。在中医外治过程中采用针灸、推拿、药浴，其中督脉炙是我们医院的特色疗法。”

人民医院中医副主任医师吴慧毅介绍说，督脉灸是在督脉的大椎穴至腰俞穴施灸，首先在这一部位盖上隔热垫，再铺上用姜碎末、川乌、肉桂、黄芪、艾绒等中药制成药粉，通过燃烧药粉施以隔药灸。起到了温阳除湿，活血散寒的功效，有利于延缓病情的进展。经过使用抗炎止痛药、免疫抑制剂类药物，配合中医理疗，小张的病症逐渐好转，已经可以正常活动，回到校园学习。目前，南平市人民医院使用中西医融合的方式，帮助许多强直性脊柱炎患者缓解病情，生活质量得到极大改善。

据了解，强直性脊柱炎是一种慢性进行性疾病,主要侵犯骶髂关节、脊柱骨突、脊柱旁软组织及外周关节,严重的可导致脊柱畸形和关节强直。它好发于青年，发病高峰阶段多在18岁至30岁之前，如果早期没有得到及时诊断，延误了最佳治疗时间，容易导致残疾。强直性脊柱炎刚发病时症状仅是腰背疼痛，它起病缓慢，病情时好时坏。风湿科副主任医师李其战在工作中发现，许多患者到了病情加重，行动吃力，驼背了才来就医。“因为许多患者误认为是腰背扭伤，腰椎间盘突出，腰肌劳损，只要休息一段时间，避免劳累就能好转。其实它最典型的症状是卧床疼痛加剧，尤其是在夜间，白天运动后疼痛就能到缓解。”医生建议，如果腰背持续疼痛超过3个月建议到医院风湿科免疫科检查，确诊患上强直性脊柱炎后，除了药物治疗和中医理疗，患者日常还应当加强体育锻炼，保持关节的灵活性，避免背部僵硬。
